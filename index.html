資料與通知設定

金鑰僅儲存在此瀏覽器 localStorage；正式部署建議使用自己的後端代理。

預設請求格式：?dataset=TaiwanFuturesTickData&data_id=TX&start_date=YYYY-MM-DD&token=...。若您的付費方案欄位或端點不同，可在原始碼的 normaliseTick 對照修改。

風險提示：此工具以成交量、推定主動方向與固定門檻產生研究訊號，不代表「大戶」真實身分、未包含未平倉量與委託簿，亦非投資建議。請先以歷史資料回測並在模擬環境驗證。

資料格式與安全說明

可貼上 FinMind 回傳的 { data: [...] } 或成交陣列。每筆至少需要時間、價格、數量；方向可用 side/buy_sell（買／賣、Buy／Sell、B／S）。沒有方向時，本頁以逐筆價格變化推定主動方。

支援常見欄位：date/time/datetime、close/price、volume/qty、data_id/symbol。小台以 0.25、大台以 1、微台以 0.05 換算為大台等值；請依契約規格自行複核。
